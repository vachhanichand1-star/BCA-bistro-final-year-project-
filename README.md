# BCA Bistro 🍽️

BCA Bistro is a full-stack online food ordering web application developed as a college project. The platform allows users to browse food menus, add items to cart, place orders, and complete secure online payments through Razorpay integration.

## Features
- User-friendly food menu browsing
- Add to cart functionality
- Online food ordering system
- Secure Razorpay payment integration
- Dynamic order processing
- Responsive UI design
- AJAX-based smooth interactions
- Database-driven content management

## Tech Stack
**Frontend:**
- HTML
- CSS
- Bootstrap
- JavaScript
- AJAX

**Backend:**
- PHP

**Database:**
- MySQL

**Payment Gateway:**
- Razorpay

## Project Type
College Academic Project

## Installation
1. Download or clone the repository
```bash
git clone https://github.com/YOUR-USERNAME/bca-bistro.git
````

2. Move project folder to XAMPP htdocs

```bash
C:/xampp/htdocs/
```

3. Import the MySQL database file into phpMyAdmin

4. Start Apache and MySQL from XAMPP

5. Open in browser

```bash
http://localhost/bca-bistro
```
